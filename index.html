1. 시작하기

페이지를 열면 안내 팝업이 떠요. 화면 아무 곳이나 클릭하면 닫혀요. 이 웹페이지는 PC 환경에서 가장 쾌적하지만, 모바일에서도 편하게 쓸 수 있도록 다듬어져 있어요.

2. 다섯 가지 모드

모드설명
🔮 상담하기카드를 뽑고 AI(Claude/Gemini)에게 해석을 받는 기본 모드
✍️ 리딩연습하기내가 먼저 직접 해석을 작성하고, AI에게 슈퍼비전(피드백) + "고수의 리딩" 예시까지 받는 연습용 모드. 실전 예시 질문 200개를 20개 카테고리(연애·이직·합격 등)로 제공
🔢 넘버 분석생년월일로 썬 넘버·문 넘버·연도 카드를 확인
💕 궁합 보기두 사람의 생년월일로 궁합을 확인
🎭 타로 인물도감메이저 아르카나 22장 + 궁정 카드 16장, 총 38장의 성격을 재미있는 글로 읽어보는 도감

⚠️ 상담하기 ↔ 리딩연습하기는 서로 다른 리딩으로 취급돼요. 모드를 전환하면 질문·배열법·뽑은 카드가 자동으로 초기화돼요.

3. 카드 뽑는 방법 세 가지

  • 🎲 직접 뽑기 — 78장이 뒷면으로 부채꼴로 펼쳐짐. 클릭 후 트레이에서 뒤집어 확인
  • 🔍 카드보며 뽑기 — 78장 전체 앞면이 나열, 원하는 카드를 보고 직접 선택
  • ✨ 랜덤 뽑기 — "🎲 지금 바로 뽑기" 버튼 한 번으로 필요한 카드를 전부 한 번에 뽑아줌

4. 배열법을 못 정하겠다면 — 자동 추천

"1 · 고민을 적어주세요"에 질문을 쓰면(직접 입력 또는 예시 질문 선택), 질문 내용을 분석해서 어울리는 배열법을 자동으로 추천해줘요. 양자택일에 어울리는 질문("~할지 ~할지", "아니면", "좋을까요/좋을까요?" 반복 등), 시기가 궁금한 질문, 상대방 마음이 궁금한 질문 등을 인식해서 최대 3개까지 추천하고, "이 배열법 적용하기"를 누르면 바로 선택돼요. (5카드·원카드는 추천 대상에서 제외되어 있어요.)

5. 배열법 전체 목록

배열법카드 수특징
원카드1장오늘의 카드
쓰리카드3장5가지 프레임 중 선택

켈틱크로스 10자리: ① 현재의 나(나의 상황) ② 장애물 ③ 환경적 요인(내적) ④ 과거 또는 원인 ⑤ 외적 요인 ⑥ 가까운 미래 ⑦ 내가 보는 나 ⑧ 남들이 보는 나 ⑨ 희망 또는 두려움 ⑩ 전체적인 결과

6. 조언 카드 추가 뽑기

필요한 카드를 다 뽑으면 "🃏 조언 카드 한 장 더 뽑기" 버튼이 나타나요. 배열법당 한 번만 사용 가능해요.

7. AI에게 물어보기 (API 키 불필요)

  1. 카드를 다 뽑고 "질문 만들기"(또는 "슈퍼비전 요청 만들기") 클릭
  2. 프롬프트 자동 생성
  3. "✦ 복사 + Claude 열기" 또는 "✦ 복사 + Gemini 열기" 클릭 → 자동 복사 + 새 창 열림
  4. 새 창에 붙여넣기(Ctrl/Cmd+V) 후 전송
  5. 받은 답변을 복사해서 이 페이지에 붙여넣고 "이 답변 표시하기" 클릭
  6. "🔮 결과 보기"를 누르면 질문·카드·AI 답변이 예쁘게 정리된 창으로 한눈에 보여요

8. 저장 · PDF · 백업

  • 💾 이 리딩 저장하기 — 브라우저에 기록 저장 (아래 "저장된 리딩" 목록에서 클릭하면 다시 볼 수 있어요)
  • ⬇️ 텍스트 파일로 저장 — .txt 다운로드
  • 🖨 PDF로 저장 — 클릭 한 번으로 PDF 파일이 바로 다운로드돼요 (인쇄창 없이 직접 저장)
  • 💾 백업 (왼쪽 상단 버튼) — 저장된 모든 리딩·넘버 분석·궁합 기록을 파일 하나로 내보내거나, 백업 파일을 다시 불러와 복원할 수 있어요

⚠️ 저장 기능은 이 브라우저에만 저장돼요(localStorage). 다른 기기·브라우저에는 안 보이니, 중요한 기록은 "💾 백업"으로 미리 받아두는 걸 추천해요.

9. 넘버 분석

  • ☀ 썬 넘버 — 생년월일 전체를 더해 1~9로 축약, 타고난 기질
  • 🌙 문 넘버 — 생월+생일을 더해 1~9로 축약, 사회적 성향
  • 🗓 연도 카드 — 올해 연도+생월+생일을 더해 21 이하로 축약, 올해의 테마

10. 궁합 보기

두 사람의 생년월일을 입력하면 각자의 썬/문/연도 카드를 비교해서, 잘 맞는 지점·갈등 지점·올해의 관계 흐름·조언을 AI에게 요청할 수 있어요.

11. 기타

  • ✦ 셔플 버튼 — 카드만 다시 섞어요 (뽑았던 카드만 초기화, 질문·배열법 설정은 유지)
  • 🔄 초기화 버튼 ("1 · 고민을 적어주세요" 옆) — 질문·배열법·뽑은 카드까지 전부 지우고 처음부터 다시 시작
  • 📖 매뉴얼 / ❓ FAQ / 💾 백업 — 왼쪽 상단 버튼들
  • 오른쪽 상단 방문자 수 — 배포된 사이트에서 자동 집계
  • 오른쪽 하단 🎵 — 배경음악 재생/정지 (직접 눌러야 재생돼요, 자동재생 아님)

❓ 자주 묻는 질문

궁금한 점, 헷갈리기 쉬운 부분을 모아봤어요

Q. API 키가 필요한가요? 돈이 드나요?
A. 전혀 필요 없어요. 완전 무료예요. Claude/Gemini도 평소 쓰시는 계정 그대로, 복사-붙여넣기로 사용하는 방식이라 별도 결제나 API 키 발급이 필요 없어요.

Q. AI 답변이 자동으로 나오는 거 아닌가요?
A. 아니요. 이 페이지는 Claude/Gemini를 자동으로 호출하지 않아요. "질문 만들기"를 누르면 프롬프트가 자동 복사되고 새 창이 열리는데, 그 창에서 직접 붙여넣기(Ctrl/Cmd+V) → 전송 → 답변을 복사해서 이 페이지에 다시 붙여넣어야 해요. 자동으로 답이 채워지는 기능은 없어요.

Q. 배열법을 선택했는데 카드가 안 눌려요.
A. "2 · 배열법을 선택해주세요"에서 배열법을 먼저 확실히 클릭해서 선택된(테두리 강조) 상태인지 확인해주세요. 배열법이 선택되지 않으면 카드 뽑기 자체가 비활성화돼요.

Q. 배열법 추천이 이상하게 나와요.
A. 질문 문장을 분석해서 추천하는 기능이라, 표현이 애매하거나 특이한 문장은 완벽하게 못 잡아낼 수 있어요. 추천은 참고만 하시고, 언제든 원하는 배열법을 직접 선택하셔도 돼요.

Q. "✨ 랜덤 뽑기"랑 "🎲 직접 뽑기"는 뭐가 달라요?
A. "직접 뽑기"는 부채에서 카드를 하나씩 직접 클릭해서 뽑는 방식이고, "✨ 랜덤 뽑기"는 "🎲 지금 바로 뽑기" 버튼 한 번으로 필요한 카드를 전부 한꺼번에 뽑아주는 방식이에요. 카드를 하나하나 고르는 느낌을 원하시면 직접 뽑기를, 빠르게 결과만 보고 싶으시면 랜덤 뽑기를 추천해요.

Q. "💾 백업"은 "저장하기"랑 뭐가 달라요?
A. "저장하기"는 리딩 한 건을 브라우저 기록에 남기는 기능이고, "💾 백업"(왼쪽 상단 버튼)은 지금까지 저장된 모든 기록을 파일 하나로 통째로 내보내거나 다시 불러오는 기능이에요. 컴퓨터를 바꾸거나 브라우저 데이터를 지우기 전에 "💾 백업 → 전체 백업 내보내기"로 미리 받아두시면 안전해요.

Q. 셔플 버튼을 누르면 질문이나 배열법도 지워지나요?
A. 아니요. "✦ 셔플"은 카드만 다시 섞어요 (뽑았던 카드만 초기화). 질문, 배열법, A/B 선택 라벨 같은 설정은 그대로 남아요. 전부 다 지우고 처음부터 시작하고 싶으면 "1 · 고민을 적어주세요" 옆의 "🔄 초기화" 버튼을 눌러주세요.

Q. 상담하기에서 뽑은 카드가 리딩연습하기로 가도 남아있나요?
A. 아니요. 두 모드는 서로 다른 리딩으로 취급해서, 모드를 전환하면 질문·배열법·뽑은 카드가 자동으로 초기화돼요. 하나의 리딩을 이어서 진행하고 싶다면 같은 모드 안에서만 작업해주세요.

Q. "저장하기"를 눌렀는데 어디서 확인하나요?
A. 각 모드 화면을 아래로 스크롤하면 "저장된 리딩"(또는 넘버 분석/궁합) 목록이 있어요. 항목을 클릭하면 예쁘게 정리된 창으로 다시 볼 수 있어요.

Q. 저장한 리딩이 다른 컴퓨터나 휴대폰에서도 보이나요?
A. 아니요. 저장은 이 브라우저에만 남아요(localStorage). 다른 기기·다른 브라우저·시크릿 모드에서는 안 보이고, 브라우저 방문 기록을 지우면 저장한 기록도 함께 사라져요. 중요한 리딩은 "🔮 결과 보기" 창에서 텍스트나 PDF로 따로 저장해두시는 걸 추천해요.

Q. 다른 사람에게 리딩 결과를 공유하려면 어떻게 하나요?
A. "🔮 결과 보기" 창을 연 뒤 "⬇️ 텍스트로 저장" 또는 "🖨 PDF로 저장"을 눌러 파일로 받은 다음, 그 파일을 카카오톡이나 이메일로 보내시면 돼요. 계정 간 자동 공유 기능은 없어요.

Q. 타로 인물도감에 78장이 다 없고 38장만 있어요.
A. 의도된 구성이에요. 메이저 아르카나 22장 + 궁정 카드(페이지·나이트·퀸·킹) 16장, 총 38장만 다루고 있어요. 나머지 숫자 카드(에이스~10) 40장은 아직 포함되어 있지 않아요.

Q. 링크로 접속했는데 예전 버전이 그대로 보여요.
A. 브라우저 캐시 때문일 가능성이 커요. 강력 새로고침(Windows: Ctrl+Shift+R / Mac: Cmd+Shift+R)을 해보세요. 특히 즐겨찾기로 들어갔을 때 이 문제가 잘 생겨요.

Q. 모바일에서도 되나요?
A. 네, 반응형으로 되어 있고 모바일 터치에 맞게 카드 크기·버튼 크기도 조정해뒀어요. 다만 가장 쾌적한 건 PC 환경이에요. 켈틱크로스처럼 카드가 많은 배열법은 모바일에서 옆으로 스크롤해서 보시면 돼요.

Q. 이 페이지가 진짜 제 운세를 "맞히는" 건가요?
A. 이 앱은 카드를 무작위로 뽑고, 그 카드+질문 정보를 AI에게 전달해서 해석을 받아보는 도구예요. 점술적 예언이 아니라 스스로를 돌아보는 참고 자료로 봐주시고, 진지한 고민은 실제 타로 마스터나 전문가와 상담하시는 걸 권해드려요 (시작 팝업에도 안내되어 있어요).
